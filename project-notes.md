# Заметки по проекту

## Тема

Мини-магазин.

## Основные сущности

- Пользователь
- Товар
- Категория
- Корзина
- Заказ

## Основная идея

Пользователь просматривает товары, добавляет их в корзину
и оформляет заказ.

## Пользовательские роли

### Покупатель
- просмотр товаров;
- добавление товаров в корзину;
- оформление заказа.

### Администратор
- добавление товаров;
- изменение товаров;
- удаление товаров;
- просмотр заказов.
