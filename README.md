# Mini Shop

Учебный проект мини-магазина для выполнения контрольной точки.

## Назначение

Проект предназначен для демонстрации работы с Git и GitHub.

## Основные возможности

- просмотр каталога товаров;
- работа с корзиной;
- оформление заказа;
- взаимодействие с API.

## Каталог

Каталог содержит список доступных товаров.

Для каждого товара отображаются:

- название;
- цена;
- категория;
- описание;
- количество на складе.

## Корзина

Пользователь может:

- добавлять товары в корзину;
- изменять количество товаров;
- удалять товары из корзины;
- просматривать итоговую стоимость.
