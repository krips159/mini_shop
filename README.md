# Mini Shop

Учебный проект мини-магазина для выполнения контрольной точки.

## Назначение

Проект предназначен для демонстрации работы с Git и GitHub.

## Основные возможности

- просмотр каталога товаров;
- работа с корзиной;
- оформление заказа;
- взаимодействие с API.

## Каталог

Каталог содержит список товаров магазина.

Для каждого товара отображаются:

- название;
- цена;
- категория;
- описание;
- количество на складе.
