# Git Conflict

## Где возник конфликт

Конфликт возник в файле `README.md`.

Две ветки изменили одну и ту же строку с описанием каталога:

- `feature/catalog-text`;
- `feature/catalog-info`.

## Как был исправлен конфликт

Git не смог автоматически определить, какой вариант текста необходимо оставить.

Конфликт был открыт в `README.md` и исправлен вручную.

Оба варианта были объединены в одну итоговую формулировку.

После исправления файл был добавлен через `git add`,
а результат сохранён отдельным коммитом:

`fix: resolve catalog description conflict`
